## 2. 来源方更正与反馈

来源方可通过[反馈页](/feedback)提交更正、下架或展示方式调整请求。请提供相关页面和原文链接，维护者会核对后处理。

## 3. 公开接口

RSS、公开 API 与 MCP 提供只读访问。请遵守接口响应中的缓存信息；收到 429 时按 `Retry-After` 等待，避免并发重试或影响服务的请求。批量保存、公开再发布或超出正常阅读的访问，应先核对来源权利和接口限制，并联系维护者确认。

## 4. 信息使用边界
